# Personal Portfolio Website

## About

This is my personal portfolio website created as part of Phase 1
using HTML5 and CSS3.

The website presents my profile, education, technical skills,
projects, activities and contact information.

## Website Structure

- **Home** – Introduction and profile photo
- **Profile** – Personal information and interests
- **CV** – Curriculum vitae and career objective
- **Education & Technical Expertise** – Education details and technical skills
- **Projects** – Academic and personal projects
- **Activities** – Activities and interests
- **Contact** – Contact form and location map

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

## Features

- Semantic HTML5 structure
- Separate pages for each section
- Navigation between pages
- Education table
- Contact form
- Embedded map using iframe
- Responsive design for desktop and mobile screens

## Design

The website uses a simple and clean design with consistent
colors, spacing, typography and navigation across all pages.
CSS Flexbox and media queries are used to make the website
responsive on different screen sizes.
